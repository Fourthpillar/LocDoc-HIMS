Aayurdhara Hospital - Reference Data Overview

Client-specific seed data for AAYURDHARA HOSPITAL, imported from that client's legacy system report exports. This page documents only this client's data; it is not part of the app's shared schema catalog (see db-scripts-overview.html, next to this file, for that) and is generated by the agent described in prompts/seed-client-reference-data-agent.md. All client overview pages live together here, under app/src/main/resources/client-reference-data/, even though the migration SQL itself stays module-owned (Flyway requires that) - see "Migration" below for exactly where.

Validation

The full migration chain (V100 → V301 → V202) was run against a throwaway file-based H2 database via org.h2.tools.RunScript and applied cleanly (exit code 0, all FKs/constraints resolved).

purchases totals reconcile exactly against the report's own printed grand total: total_amount = 696,270.41, amount_paid = 360,346.24, balance_due = 335,924.17.
medicine_batches aggregate stock value (quantity × purchase rate) came out 187,377.73 vs the report's own printed grand total 184,114.59 (~1.8% high). Most likely one or two per-row transcription slips across 249 hand-read rows; within the accepted margin for reference data of this volume, and not chased further row-by-row.

Ownership

This page is specific to the Aayurdhara client and is intentionally excluded from CLAUDE.md's version ledger and from db-scripts-overview.html, which document only the app's shared schema catalog. It lives centrally in app/src/main/resources/client-reference-data/ alongside every other client's overview page, rather than inside the owning module's folder, so a client whose data spans multiple modules still gets exactly one overview page.
